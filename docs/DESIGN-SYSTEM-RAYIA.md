# Design System RAY.IA — Dark Theme

Paleta extraída da marca (logo negativo / positivo).

| Token | Hex | Uso |
|---|---|---|
| `ray-bg` | `#0A0D14` | Fundo app |
| `ray-card` | `#121824` | Cards / painéis |
| `ray-border` | `#1E293B` | Bordas |
| `ray-blue` | `#2563EB` | Primário / CTA |
| `ray-cyan` | `#38BDF8` | Destaque IA / focus |
| `ray-neon` | `#4ADE80` | Economia / conversão |
| `ray-alert` | `#F43F5E` | Glosa crítica / anomalia |
| `ray-warning` | `#F59E0B` | Compliance ANS |

Gradientes: `bg-ray-gradient`, `bg-ray-gradient-subtle`, utilitário `text-ray-gradient`.

Assets: `apps/web/public/brand/rayia-logo-dark.png`, `rayia-logo-positive.png`.

Config: `apps/web/tailwind.config.js` + tokens em `src/tailwind.css` (`@theme`).
